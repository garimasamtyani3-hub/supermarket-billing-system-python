# supermarket-billing-system-python
An interactive Python-based supermarket billing system that processes multiple items, calculates total bill discounts, and generates an itemized receipt.
🛒 Supermarket Billing System Using Python

📌 Project Overview

The Supermarket Billing System is an interactive Python-based application developed to automate the billing process of a supermarket.

The system allows users to enter multiple items in a single transaction, calculate the price based on quantity and item price, apply discounts based on the total bill amount, and generate an itemized receipt.

🎯 Objectives

- To process multiple items in a single transaction
- To calculate the total price of each item
- To calculate the subtotal of all purchased items
- To apply discounts based on the total bill amount
- To calculate the final payable amount
- To generate an itemized bill
- To use loops for continuous item entry
- To use conditional statements for discount calculation
- To provide an interactive and accurate billing system

✨ Features

- Multiple item entry

💰 Discount Rules

The system applies discounts according to the total purchase amount.

| Total Bill Amount | Discount |
|-------------------|----------|
| ₹5,000 or more | 15% |
| ₹3,000 - ₹4,999 | 10% |
| ₹1,500 - ₹2,999 | 5% |
| Below ₹1,500 | No Discount |
